
# 理论力学(甲)

!!! abstract
	张文普老师应该是传统意义上那种非常好, 负责并且关心同学的老师吧. 许多同学都赞不绝口, 并且愿意在下学期继续上他开的材料力学课程. 本次更新笔记的时候我有幸在食堂遇到了这位可爱的老师哈哈哈.
	
	不过老师讲课的时候有些重要的地方, 尤其是逻辑上很关键的地方因为课程内容多上课时间极其紧张可能会忘记, 需要大家自己多想想多消化, 这样一来应该是能学好理论力学的.
	
	 不过如果只是希望考试取得一个好成绩, 那么可以提前看看前些年的理论力学最后一节课, 看看历年卷, 确定刷题的方向和重点理解的内容范围. 另外, 由于我们这一届的考试难度较高, 所以很多同学没能拿到比较理想符合自己预期的成绩(也包括我), 但其实这和张文普老师关系不是很大, 我很推荐上他的理论力学课程.

!!! quote
	张文普老师课前猜猜的答案: 敌军围困千万重, 我自岿然不动.

## 任课教师课程简介
---
教师: 张文普 学分: $4$

成绩构成:

- 智慧树线上课程(包括运动学, 动力学, 作为各个章节的预习与作业) $20\%$
- 平时作业与考勤 $20\%$
- 课程实验 $10\%$
- (附加到平时成绩. 平时成绩无法影响期末卷面成绩, 期末成绩, 线上成绩)竞赛, 专题报告等 $5\%$
- 期末卷面成绩 $50\%$
